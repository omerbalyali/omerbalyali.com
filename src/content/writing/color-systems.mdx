## Color Systems

We can define colors in CSS using different color systems, such as sRGB, Display-P3, and more. This allows us to create vibrant and accurate colors for our designs.

```css
.color {
	background: color(display-p3 1 0 0);
}
```

Then we can use the `color-scheme` property to specify which color systems our design supports. This helps the browser to choose the appropriate color system based on the user's device and preferences.

```html
<div data-color-scheme="dark"></div>
```

Defining the color scheme also allows us to create a consistent and cohesive design across different devices and platforms, ensuring that our colors look great no matter where they are viewed.

```css
/* Layout */
[data-theme] {
	--t-app-page-max-width: 50rem;
	--t-app-page-gutter: var(--t-space-6);

	--t-app-container-gutter-inline: max(
		var(--t-app-page-gutter),
		calc((100svw - var(--t-app-page-max-width)) / 2)
	);
}
```
